# Embedded Linux & Linux Device Driver Engineering Journey

## About This Repository

This repository documents my practical learning journey in Embedded Linux Operating Systems, Linux Kernel Development, and Linux Device Driver Development.

The objective is to develop a strong understanding of Linux internals and gain practical experience in writing, testing, debugging, and understanding Linux-based programs and device drivers.

I will maintain this repository through regular coding exercises, technical notes, experiments, and projects.

## Learning Environment

- Operating System: Zorin OS 18.1
- Programming Language: C
- Scripting Language: Bash
- Compiler: GCC
- Build System: GNU Make
- Version Control: Git and GitHub
- Development Environment: Linux Terminal
