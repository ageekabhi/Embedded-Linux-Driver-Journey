# Day 01 — Introduction to Linux

## 1. What is Linux?

Linux is an open-source, Unix-like operating system kernel.

It acts as the central component that manages hardware resources and provides essential services to software applications.

## 2. What is an Operating System?

An operating system is system software that manages computer hardware and software resources.

Examples:
- Windows
- Linux distributions
- macOS

## 3. What is a Kernel?

A kernel is the core component of an operating system.

Its main responsibilities are:

1. Process management
2. Memory management
3. Device management
4. File system management
5. CPU scheduling
6. Interrupt handling
7. Security and access control

## 4. What is a Linux Distribution?

A Linux distribution combines the Linux kernel with system utilities, libraries, package management tools and applications.

Examples:
- Ubuntu
- Debian
- Fedora
- Zorin OS

## 5. What is a Device Driver?

A device driver is software that enables the operating system to communicate with and control a hardware device.

Examples:
- GPIO driver
- I2C driver
- SPI driver
- UART driver

## 6. Linux in Embedded Systems

Linux is widely used in embedded systems because it provides:

- Multitasking
- Memory management
- Networking
- Hardware abstraction
- Device driver support
- Filesystem support
