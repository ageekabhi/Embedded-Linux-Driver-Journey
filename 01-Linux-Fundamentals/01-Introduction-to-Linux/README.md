# Day 01 — Introduction to Linux

## Objective
Understand Linux fundamentals and explore the Linux environment before starting kernel and device driver development.

## Topics Covered
- Introduction to Linux
- Operating Systems
- Linux Kernel
- Linux Distributions
- Linux Architecture
- Device Drivers
- Linux in Embedded Systems

## Practical Work
Created and executed a Bash script to retrieve:
- Operating system information
- Kernel version
- System architecture
- Hostname
- Current user
- CPU information
- Memory information

## Files
- notes.md — Detailed theory and learning notes.
- practical/day01_system_info.sh — Linux system information script.

## Learning Outcome
Understood the Linux environment, the role of the kernel, and how user-space programs interact with operating system services.
