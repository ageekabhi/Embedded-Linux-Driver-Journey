
# Terminal and Shell

## Overview

This unit introduces the Linux command-line environment, focusing on the terminal, shell, and Bash command execution process.

It explains how Bash interprets commands, identifies command types, searches for executables, and interacts with the Linux operating system.

These fundamentals are important for Linux system administration, shell scripting, embedded Linux development, and kernel programming.

## Learning Objectives

After completing this unit, you should be able to:

- Explain the difference between a terminal and a shell.
- Understand the role of Bash.
- Identify the configured shell and current shell process.
- Understand Linux command structure.
- Differentiate aliases, functions, builtins, and external executables.
- Explain the purpose of the `PATH` environment variable.
- Investigate command resolution using Bash utilities.

## Topics Covered

1. Introduction to the Linux terminal.
2. Shell fundamentals and Bash.
3. Terminal versus shell.
4. Shell environment and process identification.
5. Linux command structure.
6. Aliases and shell functions.
7. Shell builtins and external executables.
8. Command resolution.
9. PATH environment variable.
10. Command execution flow.
